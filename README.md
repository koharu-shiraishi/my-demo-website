A small storytelling site exploring why `.docx` is a fragile format for
long-term storage and sharing — and introducing WYSIWYM tools (LaTeX,
Typst) as an alternative, written through the eyes of an everyday Word
user.

## What this is

A narrative-driven explainer, told as a short story: a normal user sends
a `.docx` file, watches it break on someone else's computer, and follows
an AI chatbot's guidance to discover what's actually inside the file.
Along the way, the story introduces WYSIWYG vs. WYSIWYM, and makes the
case for plain-text, structured document formats.

This is also a personal exercise in semantic HTML and plain CSS —
built without frameworks, to stay readable and easy to maintain.

## Chapters

1. The Day Your Document Broke
2. The Dark Side of a Popular Tool
3. Where's My Familiar Icon?
4. WYSIWYM: A Different Way to Write
5. A Brief Chronology

## Tech stack

- Plain CSS (no framework), targeting a simple, document-like look
