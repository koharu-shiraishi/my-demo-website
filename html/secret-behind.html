The Secret Behind the .docx File

At this point, you search the internet for a fix: "why does my Word document look different on another computer". An AI-generated summary appears above the search results: click the file once to select it, press F2, and type the same name again but add .zip at the very end — then press Enter. The document's content will be inside as XML. Below the summary is a chat box, in case you want to ask more. A repair trick — and also an accidental confession: a .docx file is secretly a ZIP archive.

You don't have to trust it blindly. You can verify this yourself in two minutes, with the tools already on your computer. You open File Explorer, find the .docx file you recently sent, and decide to follow the instructions — starting with the file name.

Side note: File Explorer shows storage sizes in MB instead of the correct unit, MiB — a small inaccuracy that has confused generations of users.

If terms like "file extension" or "archive" feel unfamiliar, that's not a personal failing — it's by design. Windows has hidden these details from users for over three decades, precisely so that most people never need to think about what a file actually is. This article asks you to look anyway.
